LAS CAZADORAS, MACA Y LA ESTRELLA DE LOS SUEÑOS

1. Abre index.html en Chrome, Edge, Firefox o Safari.
2. Pulsa “Abrir el libro”.
3. Usa los botones laterales, las flechas ← → del teclado o desliza en móvil/tablet.
4. ESC cierra el libro y vuelve a la portada.

Archivos fuente:
- index.html
- js/story.js
- scss/main.scss
- css/main.css
- assets/images/chapter-01.png ... chapter-09.png

Nota: las tipografías decorativas se cargan desde Google Fonts. Si no hay Internet, el navegador utilizará Georgia como alternativa.
